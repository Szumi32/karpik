# Karpik: domki nad Jeziorem Białym

Pokazowa, statyczna wersja strony gospodarstwa agroturystycznego Karpik: https://szumi32.github.io/karpik/

Strona działa bez serwera. Podstrony, galerie, kalendarz wolnych terminów z cenami i asystent odpowiadający z bazy wiedzy działają w przeglądarce. Rezerwacja i wiadomość z formularza otwierają się jako gotowy e-mail do właściciela. Zajęte terminy w kalendarzu to dane demonstracyjne, a numer telefonu i e-mail są przykładowe.

Pliki powstają automatycznie (`npm run pages` w projekcie strony), więc zmiany wprowadza się w projekcie, a nie tutaj.
