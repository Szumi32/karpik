# Domki nad Białym

Pokazowa, statyczna wersja strony Domków nad Białym, domków do wynajęcia nad Jeziorem Białym: https://szumi32.github.io/karpik/

Strona działa bez serwera. Podstrony, galerie, kalendarz wolnych terminów z cenami i asystent odpowiadający z bazy wiedzy działają w przeglądarce. Rezerwację ustala się telefonicznie lub przez formularz.

Zajęte terminy leżą w pliku `data/blocks.json`. Właściciel zmienia je w panelu na telefonie (https://szumi32.github.io/karpik/panel/), a strona od razu pokazuje je jako niedostępne. Numer telefonu i e-mail są przykładowe.

Pliki powstają automatycznie (`npm run pages` w projekcie strony), więc zmiany wprowadza się w projekcie, a nie tutaj.
